# Волна — музыкальный плеер для Android

Своё приложение под Pixel 7 Pro (работает на Android 10+).

## Что умеет
- **Плейлист** — вставляешь ссылку на плейлист / трек / профиль SoundCloud (или «Поделиться» из приложения SoundCloud → Волна), слушаешь онлайн.
- **Скачивание** — треки, у которых автор включил кнопку Download, скачиваются в оригинальном качестве прямо в память приложения и играют офлайн.
- **Медиатека** — офлайн-треки, поиск, перемешивание, импорт своих аудиофайлов с телефона.
- **Волна** — бесконечный поток похожей музыки: лайк / дизлайк / пропуск, подстраивается под вкус.
- **Эквалайзер** — 10 полос (32 Гц – 16 кГц), 11 пресетов, лимитер против хрипа.
- Фоновое воспроизведение, уведомление с кнопками, экран блокировки, наушники.

## Как получить APK (без установки чего-либо на компьютер)
1. Создай на github.com новый репозиторий (можно приватный).
2. Нажми **Add file → Upload files** и перетащи **всё содержимое** папки `Volna` (включая папки `.github`, `app`, `gradle`, `keystore`). Нажми **Commit changes**.
3. Открой вкладку **Actions** — сборка запустится сама (~5–7 минут).
4. Когда появится зелёная галочка, открой **Releases** (справа на главной странице репозитория) → скачай `Volna.apk` прямо с телефона и установи.

Новая версия кода → снова загрузи файлы → новый APK появится в Releases и установится поверх старого.

## Сборка в Android Studio
Открой папку `Volna` → дождись синхронизации → Build → Build APK(s).
